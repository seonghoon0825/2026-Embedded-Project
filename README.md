## 1. 프로젝트 개요

사용자의 접근을 감지하여 물리적 접촉 없이 쓰레기통 뚜껑을 자동으로 열고 닫음으로써 위생과 편의성을 증대

**핵심 기술**

- 초음파 거리 측정 (음파 왕복 시간 → 거리 환산)

$$
Distance = \frac{Time \times Velocity}{2}

$$

- PWM 제어: ESP32 LEDC 기능으로 서보모터 각도를 정밀 제어
- 상태 제어: 감지 → 열림 → 유지 → 닫힘
- 잔량 감지: 내부 초음파 센서로 잔량 % 계산 → LED + 부저 알림

## 3. 핀 배치

> **주의: LOLA 보드 전용 핀은 절대 사용 금지**
> GPIO 13 (온보드 LED), GPIO 14 (LED 스트립), GPIO 16 (버튼), GPIO 18/19 (PDM 마이크)

### 외부 초음파 센서 (손 감지)


| HC-SR04 핀 | LOLA 핀 | 비고                              |
| :----------: | :--------: | :---------------------------------- |
|    VCC    | VIN (5V) |                                   |
|    GND    |   GND   |                                   |
|    TRIG    | GPIO 26 |                                   |
|    ECHO    | GPIO 25 | **전압분배 회로 필수** (5V→3.3V) |

### 서보모터


| 서보 선 색 | LOLA 핀 | 비고     |
| :----------: | :--------: | :--------- |
| 빨간 (VCC) | VIN (5V) |          |
| 갈색 (GND) |   GND   |          |
| 주황 (PWM) |  GPIO 4  | LEDC ch0 |

### 내부 초음파 센서 (잔량 측정)


| HC-SR04 핀 | LOLA 핀 |
| :----------: | :--------: |
|    VCC    | VIN (5V) |
|    GND    |   GND   |
|    TRIG    | GPIO 35 |
|    ECHO    | GPIO 36 |

### 잔량 LED + 부저


|        부품        | LOLA 핀 | 의미            |
| :------------------: | :-------: | :---------------- |
| LED 초록 (+ 220Ω) | GPIO 34 | 잔량 0~50%      |
| LED 노랑 (+ 220Ω) | GPIO 33 | 잔량 50~80%     |
| LED 빨강 (+ 220Ω) | GPIO 32 | 잔량 80~100%    |
|        부저        | GPIO 27 | 80% 이상 경고음 |

## 4. 전압 분배 회로 (ECHO 핀 필수)

HC-SR04의 ECHO 핀은 5V 신호를 출력하지만, ESP32는 3.3V 입력만 허용한다.
1kΩ + 2kΩ 저항으로 전압을 분배해야 ESP32가 손상되지 않는다.

```
HC-SR04 ECHO (5V)
        │
       1kΩ
        │
        ├──── GPIO 25 (ESP32)
        │
       2kΩ
        │
       GND

출력 전압 = 5V × 2kΩ / (1kΩ + 2kΩ) = 3.33V  ✓
```

## 6. 동작 시나리오

```
[부팅]
  └─ 서보 0°(닫힘) 초기화
  └─ LED 순서 점등 테스트 (초록 → 노랑 → 빨강)
  └─ 시리얼 모니터 초기화 완료 메시지 출력

[메인 루프 - 100ms 주기]
  외부 센서 측정
    ├─ 거리 ≤ 30cm → 손 감지
    │     └─ 서보 100° → 뚜껑 열림
    └─ 거리 > 30cm
          └─ 손 있었으면 타이머 시작
                └─ 3초 경과 → 서보 0° → 뚜껑 닫힘

[메인 루프 - 2000ms 주기]
  내부 센서 측정 (잔량 계산)
    잔량 = (1 - 내부거리 / 쓰레기통높이) × 100%
    ├─  0~50% → 초록 LED
    ├─ 50~80% → 노랑 LED
    └─ 80~100% → 빨강 LED + 부저 3회 경고음
```

## 7. 개발 환경 세팅

### Arduino IDE 설정

1. Arduino IDE 설치: https://www.arduino.cc/en/software
2. 환경설정 → 추가 보드 URL:
   ```
   https://dl.espressif.com/dl/package_esp32_index.json
   ```
3. 보드 매니저에서 `esp32` 검색 → 설치
4. **Tools → Board → ESP32 Arduino → ESP32 Dev Module** 선택
5. Tools → Upload Speed → `115200`
6. Tools → Port → LOLA 연결된 포트 선택

### 필수 라이브러리 설치

Tools → Manage Libraries 에서 아래 검색 후 설치:


| 라이브러리      | 설치 이름    |
| :---------------- | :------------- |
| ESP32 서보 제어 | `ESP32Servo` |

> **주의:** 일반 `Servo.h`는 ESP32에서 충돌 가능성이 있으므로 반드시 `ESP32Servo` 사용

### 코드 업로드

1. LOLA 보드를 USB로 연결
2. `src/main.cpp` 파일 열기
3. 업로드 버튼 클릭
4. Tools → Serial Monitor → 속도 `115200` 설정 → 동작 로그 확인

## 8. 코드 주요 설정값

`src/main.cpp` 상단에서 아래 값을 조정할 수 있다.

```cpp
#define DETECT_DIST_CM      30    // 손 감지 거리 (cm)
#define CLOSE_DELAY_MS    3000    // 손 없어진 후 닫힘 대기 (ms)
#define BIN_HEIGHT_CM       40    // 쓰레기통 내부 높이 (실측 후 수정)
#define FULL_THRESHOLD_PCT  80    // 부저 울리는 잔량 기준 (%)
#define SERVO_OPEN_DEG     100    // 뚜껑 열림 각도 (실물 맞춰 조정)
```

## 9. 물리적 조립 방법

**서보모터 (뚜껑 개폐)**

- 서보모터를 쓰레기통 몸통 옆면에 나사 또는 핫글루로 고정
- 서보 혼(회전 팔)을 뚜껑과 철사 또는 링크로 연결
- 서보가 100° 돌 때 뚜껑이 완전히 열리도록 위치 조정

**외부 초음파 센서 (손 감지)**

- 쓰레기통 앞면 또는 뚜껑 앞쪽에 구멍 두 개 타공
- HC-SR04 송신/수신 원통이 바깥으로 나오게 고정
- 핫글루건으로 틈 밀봉

**내부 초음파 센서 (잔량 측정)**

- 쓰레기통 뚜껑 안쪽 천장 중앙에 부착 (바닥을 향하도록)
- `BIN_HEIGHT_CM` 값을 실제 센서~바닥 거리로 수정

**ESP32 LOLA + 배터리**

- 쓰레기통 옆면 또는 안쪽에 양면테이프로 고정
- 배터리팩은 안쪽 하단에 배치
