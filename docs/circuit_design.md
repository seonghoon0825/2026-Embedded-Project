# 비접촉식 스마트 쓰레기통 회로도

이 문서는 ESP32, HC-SR04 초음파 센서, 서보 모터를 사용해 쓰레기통 뚜껑을 자동으로 여닫는 기본 회로를 정리한 문서입니다.

시각 회로도 파일은 `docs/circuit_diagram.svg`입니다.

## 1. 사용 부품

| 부품 | 수량 | 용도 |
| --- | ---: | --- |
| ESP32 개발 보드 | 1 | 센서 측정 및 서보 모터 제어 |
| HC-SR04 초음파 센서 | 1 | 사용자 접근 거리 측정 |
| 서보 모터 | 1 | 쓰레기통 뚜껑 개폐 |
| 5V 외부 전원 | 1 | 서보 모터 전원 공급 |
| 저항 1k ohm | 1 | Echo 전압 분배 |
| 저항 2k ohm | 1 | Echo 전압 분배 |
| 점퍼선 | 필요 수량 | 부품 연결 |

## 2. 전체 연결도

```text
                         +----------------------+
                         |        ESP32         |
                         |                      |
HC-SR04 VCC -------------+ 5V 또는 VIN          |
HC-SR04 GND -------------+ GND                  |
HC-SR04 TRIG ------------+ GPIO 5               |
HC-SR04 ECHO ---[1k]-----+ GPIO 18              |
                 |       |                      |
                [2k]     |                      |
                 |       |                      |
GND -------------+-------+ GND                  |
                         |                      |
Servo Signal ------------+ GPIO 19              |
                         +----------------------+

External 5V (+) --------- Servo VCC
External 5V (-) --------- Servo GND
External 5V (-) --------- ESP32 GND
```

## 3. 핀 연결표

| 부품 핀 | 연결 위치 | 설명 |
| --- | --- | --- |
| HC-SR04 VCC | ESP32 5V 또는 VIN | 초음파 센서 전원 |
| HC-SR04 GND | ESP32 GND | 초음파 센서 접지 |
| HC-SR04 TRIG | ESP32 GPIO 5 | 초음파 송신 시작 신호 |
| HC-SR04 ECHO | 저항 분배 후 ESP32 GPIO 18 | 초음파 반사 시간 입력 |
| Servo Signal | ESP32 GPIO 19 | 서보 모터 PWM 제어 신호 |
| Servo VCC | 외부 5V + | 서보 모터 전원 |
| Servo GND | 외부 5V - 및 ESP32 GND | 공통 접지 |

## 4. Echo 전압 분배 회로

HC-SR04의 Echo 핀은 일반적으로 5V 신호를 출력합니다. ESP32 GPIO는 3.3V 입력을 사용하므로 Echo 신호를 그대로 연결하지 말고 저항 2개로 전압을 낮춥니다.

```text
HC-SR04 Echo ----[1k ohm]----+---- ESP32 GPIO 18
                             |
                           [2k ohm]
                             |
                            GND
```

이 연결은 약 5V Echo 신호를 약 3.3V로 낮춰 ESP32 입력 핀을 보호합니다.

## 5. 전원 연결 주의사항

- 서보 모터 전원은 ESP32의 3.3V 핀에서 직접 공급하지 않습니다.
- 서보 모터는 순간 전류가 크므로 가능하면 별도의 5V 전원을 사용합니다.
- 외부 5V 전원의 GND와 ESP32 GND는 반드시 연결해야 합니다.
- GND를 공통으로 연결하지 않으면 PWM 신호 기준이 맞지 않아 서보 모터가 떨리거나 동작하지 않을 수 있습니다.
- USB 전원만으로 서보 모터를 구동하면 ESP32가 재부팅될 수 있습니다.

## 6. 코드 기준 핀 설정

`src/main.cpp`의 기본 핀 설정은 다음과 같습니다.

```cpp
const int TRIG_PIN = 5;
const int ECHO_PIN = 18;
const int SERVO_PIN = 19;
```

회로의 GPIO 번호를 바꾸면 코드의 핀 상수도 함께 수정해야 합니다.

## 7. 동작 확인 순서

1. ESP32와 HC-SR04만 연결한 뒤 시리얼 모니터에서 거리 값이 변하는지 확인합니다.
2. 서보 모터를 외부 5V 전원에 연결하고 GND를 ESP32와 공통으로 묶습니다.
3. 손을 센서 앞 10cm 이내로 가져갔을 때 서보 모터가 열림 각도로 움직이는지 확인합니다.
4. 손을 치운 뒤 약 3초 후 닫힘 각도로 돌아오는지 확인합니다.
5. 뚜껑을 장착한 뒤 `OPEN_ANGLE`, `CLOSE_ANGLE` 값을 실제 구조에 맞게 조정합니다.
